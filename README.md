# Free-Space-QKD

Os codigos do projeto ficam em `Codigos/`.

Para executar o experimento, comece por
`Codigos/programas_principais/README.md`. Essa pasta concentra os programas de
camera, caracterizacao, centro de massa, calibracao e tracker.

As notas de continuidade ficam em `Anotaçoes/notas.md`. Elas guardam decisoes e
resultados datados; para saber o que o codigo faz hoje, use os README e os
arquivos de `Codigos/modulos/configuracoes/`.

Resultados e materiais locais permanecem fora do versionamento normal do Git.
